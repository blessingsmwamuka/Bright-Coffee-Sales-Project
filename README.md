
Bright Coffee Sales Project

Project Overview

This project presents a comprehensive sales analysis of historical transactional data from **Bright Coffee Shop**.

The analysis was designed to provide business insights for a newly appointed CEO, with the goal of improving revenue performance and optimizing product strategy through data analytics and visualization.


🎯 Project Objective

Use data analytics and visualization to answer key business questions and provide actionable recommendations.
 
❓ Business Questions

- Which products generate the most revenue?
- What time of day does the store perform best?
- What sales trends exist across product types and time intervals?
- What recommendations can improve sales performance?

📋 Project Tasks

 Task 1: Planning & Architecture

- Developed the project workflow.
- Designed the data flow and ETL architecture using **Miro**.
- Outlined the key insights required to guide the analysis.


Task 2: Data Processing

- Converted raw Excel data into CSV format.
- Loaded the dataset into **Databricks**.
- Cleaned and transformed the data for analysis.


Task 3: Data Visualization & Insights

- Built dashboards and visualizations.
- Presented findings using **PowerPoint** and **Canva**.
- Generated business insights and recommendations.


📈 Project Outcome

The analysis identified:

- Top-performing products
- Peak sales periods
- Sales trends across categories
- Actionable recommendations to improve revenue and customer engagement
